Selectors are Keccak-derived from exact signatures. `getPoolTokens(address)` uses `0xca4f2803`; token metadata `decimals()`, `symbol()`, `name()`, `totalSupply()`, balances `balanceOf(address)`; ERC4626 `asset()` is optional. `getPoolTokenInfo(address)` returns token/address and balance arrays, never a price. Both token addresses and pool addresses must be real EVM addresses, and all dynamic arrays need strict length/offset limits. Metadata calls are not atomic across latest-block RPC heads; annotate block provenance.
