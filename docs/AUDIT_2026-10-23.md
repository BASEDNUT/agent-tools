## Unresolved production blockers

**This release does not fulfill complete live autonomous operation.** The following cannot truthfully be called validated or implemented at production level:

- Live Base mainnet/Sepolia interaction, RPC provider quorum, historical archival completeness, full block-range backfills and unattended high-availability index services.
- Complete contract build artifacts and ABI proofs; SDK patch check needs the actual complete patched artifact and source registry files, not fixture JSON.
- Canonical Orchard V25 identity/LP token mapping, full wallet positions, ELO/rank algorithm, Grove assignment and deployed eligibility enforcement. Operator-supplied configuration intentionally cannot assert project approval.
- Authenticated timestamped USD prices with historical data; 24h volume/TVL alignment, turnover/APR and audited economic calculations. Single-point operator USD price snapshots support reproducible arithmetic only.
- Multi-pool verified smart order routing, effect-level calldata firewall, MEV and slippage guarantees.
- Cryptographic principal authentication, out-of-process execution permissions, durable concurrent spending policy, independently secured/hardware wallet signer, transaction submission, external security audit and policy-controlled on-chain transaction recovery.
- Independent conformance testing with external MCP client runtimes and deployment-grade HTTP authentication. Current loopback API MUST NOT be exposed publicly.

**Safety**: There is no financial signing/broadcast or transaction execution path. An unsigned envelope or `eth_call` is not permission to move funds. Payments/x402 remain excluded at user direction.

## Incremental improvement rule

Proceed source-by-source. No false completion from a callable name: every protocol-level capability requires a canonical source, deterministic unit and adversarial tests, live verification where applicable, a documented threat boundary, and packaging through shared CLI/MCP/SDK/API. V25 Orchard remains unmodified until its own data contract is established.
